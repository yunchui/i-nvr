运行参数

门禁访问密码

进入本系统所需的访问密码（独立于米家账号）。修改后需用新密码重新解锁；原“一键解锁链接”会失效。当前已登录会话不会被退出。

凭当前密码生成免密解锁链接，打开即进入系统，等同于密码，请勿外发或用于公网；修改密码后旧链接失效，需重新生成。

HLS 预览参数

网页 HLS 实时预览的分片与预热设置。保存后立即生效：分片时长/窗口/音频会让正在进行的预览短暂中断后自动恢复；预热开关下一轮自动生效。

共享看板参数

免鉴权共享大屏的事件、心跳与轮询周期。事件时长对下一次触发生效，心跳周期下一轮生效；轮询/兜底重载在大屏下次加载时生效。
